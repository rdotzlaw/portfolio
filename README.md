# Portfolio website

Built using `Astro` and [Fuwari template](https://github.com/saicaca/fuwari)

### Setup

1. Clone repo
2. Install dependencies: `pnpm install`
    - Install `pnpm` with `npm install -g pnpm`
3. Site config in `src/config.ts`
4. Create new post w/ `pnpm new-post <file-name>`
5. Deploy according to one of [these guides](https://docs.astro.build/en/guides/deploy/)
    - need to edit site config in `astro.config.mjs` before deployment
